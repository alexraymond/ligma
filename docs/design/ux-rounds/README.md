# UX thought-experiment rounds — 2026-08-14

Four rounds of "put yourself in a user's shoes" walks against the current UI and
docs/design/UX-REDESIGN.md. Round 1 (solo technical founder — Alex's own shape) ran in
conversation and produced amendments A–F, recorded in UX-REDESIGN.md Part 3. Rounds 2–4
ran as independent opus passes; their full reports are preserved verbatim here:

- round-2-nontechnical.md — founder, designer, PM, intermittent sole approver.
  Amendments G1–G15. Headline: money, reversal, and "show me the thing" are the three
  clusters the proposal never looked at; most fixes are placement/naming because the
  reassuring machinery already exists and is a secret.
- round-3-power-users.md — keyboard-first dev, 15-client agency operator, control
  skeptic, the unsticker. Amendments H1–H13. Headline: strong answer to navigation,
  weak answer to scale/observability/control; cost is unrecorded (not just unshown);
  the machine itself has no home in a project-scoped stage model.
- round-4-lifecycle.md — three-weeks-away return, overnight disaster, month-six decay,
  quota-exhausted/daemon-down day, client handoff, out-of-band edits. Amendments
  J1–J16. Headline: the redesign deletes the only real stop; several adopted
  amendments (C, E, activity drawer) depend on data fields that don't exist.

The synthesis — merged amendment register, conflict resolutions, revised phases, and
the fix-now bug list — is UX-REDESIGN.md Part 3.
