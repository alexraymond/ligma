# Skills

Functional skills the agent invokes to do work on user input, plus a curated
catalogue of design/creative skill stubs — one flat directory, each entry a
folder with a `SKILL.md`.

See [`AGENTS.md`](./AGENTS.md) for the full contract: how this repo serves
this directory (`GET /api/skill-catalog`, surfaced on the Library page's
"skill-catalog" tab), how to add a skill, and the curated-catalogue story.
